SOBRE ESTE PROYECTO
Que es: Dashboard de produccion para desfiles de moda. Disenado como herramienta interna de trabajo para productoras de fashion shows — organiza informacion general, moodboards visuales, coleccion de prendas, timeline de produccion, equipo, presupuesto, musica, proceso creativo y notas en un solo lugar navegable con tabs.
Logica: La produccion de un fashion show genera informacion dispersa entre documentos, planillas, chats y carpetas de Drive. Este dashboard centraliza todo en una interfaz interactiva donde el equipo puede consultar y editar cada modulo en tiempo real. Las tabs permiten navegar entre secciones sin perder contexto. Cada seccion se puede descargar como PDF para compartir con proveedores o equipo externo. La persistencia local permite trabajar offline.
Stack: HTML + CSS + JavaScript vanilla. Single-file, sin frameworks ni dependencias externas. Persistencia con localStorage. Sistema de tabs, modales, export/import JSON, descarga de secciones como PDF, toggle de idioma ES/EN. Deploy estatico en Vercel. Diseno responsive. La version en produccion utiliza Firebase Firestore para sincronizacion en tiempo real entre dispositivos.
Rol: Product management, diseno de informacion, arquitectura del dashboard, desarrollo front-end, sistema i18n, deploy y entrega al cliente.
⚠ Nota: Toda la informacion presentada en este dashboard es ficticia. Los nombres, datos, contactos, presupuestos y detalles fueron creados exclusivamente para esta demostracion. El dashboard original fue desarrollado para un cliente real cuya identidad y datos se preservan por confidencialidad.
